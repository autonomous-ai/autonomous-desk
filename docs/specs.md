# Autonomous Smart Desk Pro — Specifications

Reference specs for builders. Use these when sizing motor controllers, choosing legs, designing the frame, or validating a DIY build.

## Dimensions

| Parameter | Value |
|-----------|-------|
| Frame footprint | 40.4" – 70.9" L × 26.4" W |
| Top size | 53" L × 29" W × 1.2" H |
| Height range | 29.5" – 48.5" (seated to standing) |

## Performance

| Parameter | Value |
|-----------|-------|
| Motor | Dual |
| Lift speed | 1.2" / sec |
| Noise level | < 30 dB |
| Weight capacity | 330 lbs (150 kg) |
| Anti-collision | Yes |

## Materials

| Component | Material |
|-----------|----------|
| Frame | SPCC steel |
| Desktop top | HDF wood, Green Standard sealed |

## Certifications

- ANSI/BIFMA (structural and ergonomic)
- Green Standard (low-emission surface finish)

## Warranty (OEM reference)

| Part | Warranty |
|------|----------|
| Frame | Lifetime |
| Top | 2 years |
