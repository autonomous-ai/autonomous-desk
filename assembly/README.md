# Assembly Guide

How to build the desk, step by step.

## Before You Start

1. Read the full guide first
2. Get all parts (`bom/parts.csv` and `electronics/bom/parts.csv`)
3. Print all CAD parts (`cad/stl/`)
4. Tools needed: hex keys, screwdriver, soldering iron, multimeter

## Time

About 4-6 hours for a first build.

## Troubleshooting

- Motor not moving → check driver power and direction pin
- Display blank → check 3.3V to display, check SPI wiring
- Wi-Fi not connecting → hold reset for 5s to clear config

More in `docs/troubleshooting.md`.
